# Extension Icons

This directory should contain the following icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using any image editing software. Here are some suggestions:

### Design Guidelines

1. **Theme**: Academic/educational with a security/warning element
2. **Colors**: Use purple/blue tones (matching the extension theme: #667eea, #764ba2)
3. **Symbol**: Consider using:
   - A shield with a graduation cap
   - A magnifying glass over a document
   - A checkmark with academic symbols
   - Warning triangle with academic elements

### Quick Creation Methods

**Option 1: Use Figma or Canva**
- Create a 128x128 design
- Export as PNG in three sizes (16x16, 48x48, 128x128)

**Option 2: Use GIMP or Photoshop**
- Design at 128x128 with high resolution
- Scale down to create smaller versions

**Option 3: Use Online Tools**
- [Favicon Generator](https://favicon.io/)
- [Icon8](https://icons8.com/)
- [Flaticon](https://www.flaticon.com/)

**Option 4: Use AI Image Generators**
- Generate with prompts like: "academic conference shield icon, purple gradient, flat design"
- Resize to required dimensions

### Temporary Placeholder

For development/testing, you can use solid color squares:
- Create 16x16, 48x48, and 128x128 purple squares with "AC" text overlay
